Cara Deploy Web

Ikuti langkah mudah ini untuk merilis web buatanmu ke internet secara gratis:

1. Persiapkan File

Simpan kode HTML/CSS/JS yang kamu dapatkan dari AI ke dalam satu file bernama index.html di komputer/HP kamu.

2. Daftar Vercel

Buka vercel.com/signup dan daftar menggunakan akun GitHub atau Google kamu secara gratis.

3. Upload Project

Setelah login, klik tombol "Add New..." lalu pilih "Project". Kamu bisa meng-upload folder project atau menghubungkan repository GitHub kamu.

4. Deploy

Klik tombol "Deploy". Tunggu beberapa detik hingga proses build selesai, dan web kamu akan langsung online dengan link gratis dari Vercel!
